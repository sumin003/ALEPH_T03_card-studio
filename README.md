# 짤·카드 스튜디오 (Card Studio)

이미지와 문구를 조합해 짤·카드·SNS 게시용 이미지를 제작하고 PNG 파일로 저장할 수 있는 웹 편집 도구입니다.

별도의 로그인 없이 이미지와 문구를 편집할 수 있으며, 사용자가 만든 템플릿을 저장하고 다시 활용할 수 있습니다.

## 주요 기능

### 이미지 편집
- PNG·JPEG 이미지 불러오기 및 제거
- 1:1, 4:5, 9:16 비율 선택
- 투명·단색·그라데이션 배경 설정
- 색상 코드 직접 입력

### 문구 편집
- 여러 문구 추가 및 삭제
- 미리보기에서 문구 선택·이동·직접 편집
- 글꼴, 크기, 색상, 기울기 변경
- 그림자 방향 및 거리 조절

### 이미지 저장
- 편집 결과를 PNG 이미지로 저장
- 1:1 — 1080 × 1080
- 4:5 — 1080 × 1350
- 9:16 — 1080 × 1920

### 템플릿 관리
- 기본 템플릿 3개: 응원 카드, 좋은 하루, 오늘의 기록
- 사용자 템플릿 생성·불러오기·수정·삭제
- IndexedDB를 이용한 브라우저 내 사용자 템플릿 저장
- Supabase Storage에서 기본 템플릿 이미지 및 JSON 불러오기

## 사용 방법

1. 이미지를 불러오거나 배경을 설정합니다.
2. 원하는 비율을 선택합니다.
3. 문구의 내용·위치·크기·색상 등을 편집합니다.
4. 미리보기에서 결과를 확인합니다.
5. **저장하기** 버튼을 눌러 PNG 파일로 내려받습니다.

자주 사용하는 설정은 **템플릿 저장** 기능으로 보관하고 다시 사용할 수 있습니다.

## 사용 기술

| 기술 | 사용 목적 |
|---|---|
| HTML | 화면 구조 |
| CSS | 디자인 및 반응형 레이아웃 |
| JavaScript | 편집 기능과 PNG 저장 |
| Canvas API | 이미지 렌더링 및 내보내기 |

## 극단 입력 12건 검사 결과 (T03-C14)

긴 한글 문장, 한글·영문 혼합, 직접 줄바꿈, 이모지, 빈 문구, 최대 글자 수, 세로·가로 이미지, 투명 PNG, 큰 글자·회전, 잘못된 파일, 비율 변경·재저장 등 총 12가지 상황을 검사하였습니다.

| 번호 | 검사 항목 | 최종 결과 |
|---|---|---|
| 1 | 긴 한글 문장 | PASS |
| 2 | 한글·영문 혼합 | PASS |
| 3 | 직접 줄바꿈 | PASS |
| 4 | 이모지 | PASS |
| 5 | 빈 문구 | PASS |
| 6 | 최대 글자 수 120자 | PASS |
| 7 | 세로 이미지 | PASS |
| 8 | 가로 이미지 | PASS |
| 9 | 투명 PNG | PASS |
| 10 | 큰 글자·회전 | PASS |
| 11 | 잘못된 파일 | PASS |
| 12 | 비율 변경·재저장 | PASS |

검사 과정에서 발견된 투명 PNG 저장 문제와 큰 글자·회전 시 미리보기와 저장 이미지가 일치하지 않는 문제를 수정하였습니다.

**최종 검사 결과: PASS 12건 / FAIL 0건**

※ 최종 PASS 결과는 프로젝트 제작자가 수정 및 재확인한 결과를 반영했습니다.

## 보안 및 데이터 관리

- 사용자 템플릿은 해당 브라우저의 IndexedDB에 저장됩니다.
- 브라우저 데이터를 삭제하거나 다른 브라우저·기기를 이용하면 저장된 템플릿을 사용할 수 없을 수 있습니다.
- 기본 템플릿은 Supabase Storage의 공개 PNG·JSON 파일을 사용합니다.
- 프로젝트 코드에 Supabase 비밀 API 키나 관리자 인증 정보를 포함하지 않았습니다.
- 공개 저장소에 비밀키나 개인정보를 올리지 않도록 주의합니다.

## 개발 및 실행

`index.html`, `style.css`, `script.js`를 같은 폴더에 두고 `index.html`을 실행하거나 정적 웹 호스팅으로 배포할 수 있습니다.

Google Fonts와 Supabase 기본 템플릿을 불러오려면 인터넷 연결이 필요합니다.
